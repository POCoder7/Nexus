# ADR-010: Track the programme in Excel for now

- **Status:** Accepted
- **Date:** <set when reviewed>
- **Deciders:** <names / roles>
- **Capabilities:** ALL

## Context
Team preference and low setup cost at programme start.

## Decision
Use the programme tracker workbook (capabilities, stories, tests, milestones, RAID, decisions) with weekly updates, kept on shared co-authoring storage, not in this repository.

## Alternatives considered
- Jira/Confluence.
- Azure DevOps.

## Consequences
Manual updates and limited concurrency; revisit when the team grows.
