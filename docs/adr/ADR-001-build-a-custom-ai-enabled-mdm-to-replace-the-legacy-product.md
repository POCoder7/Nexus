# ADR-001: Build a custom AI-enabled MDM to replace the legacy product

- **Status:** Accepted
- **Date:** <set when reviewed>
- **Deciders:** <names / roles>
- **Capabilities:** ALL

## Context
The legacy hierarchy-management product is an ageing on-premises platform. The organisation wants AI assistance, beneficial-ownership analysis and a modern user experience it cannot get from it.

## Decision
Replace it with a custom-built platform (Nexus).

## Alternatives considered
- Vendor cloud successor: hierarchy-focused, no ownership graph, limited AI.
- Keep the legacy product and add an ownership-graph satellite: two systems of record for entity identity.

## Consequences
Full control of roadmap and design; the organisation carries build and run cost. Parity must be proven objectively (see ADR-009).
