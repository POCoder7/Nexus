# Rule library for the hackathon data set (ADR-046 D5, Phase 4 LLD §17.5)

One file per rule code of `validation_rules.csv` that is not a database guard (VR02, VR05 to VR08 are guards; VR00 is
a FEED rule and is skipped). The loader stores the file as the rule's expression; a rule without a file is stored
inactive. Each query follows the rule contract of `validate_change_request`: it returns `(node_id, hierarchy_id,
message)` rows, `$1` is the business date, and only findings on nodes the request affects are kept. Facts are read as
currently believed (`upper_inf(recorded_period)`). `{{hierarchy}}` is replaced, as a quoted literal, by the hierarchy
code in the rule's `applies_to`.

Reviewed SQL only; never generated by a model (CLAUDE.md rule 4).
